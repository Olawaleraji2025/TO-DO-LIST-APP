# TO-DO LIST 

Hey there! Welcome to the **Todo List Application** – your friendly companion for staying organized and crushing those daily tasks. Whether you're juggling work deadlines, personal errands, or just trying to remember to water the plants, this app has got your back. It's a simple, web app built with JavaScript, HTML, and CSS, designed to make productivity feel effortless and fun.

## FEATURES:

- **Add, edit, and delete tasks**: Users will be able to Create tasks with custom text, Double-click or tap the edit button to change task details right in place and Remove tasks you no longer need, keeping your list clutter-free.

- **Mark tasks as complete with visual feedback**: Users can mark tasks as you complete them

- **Filter tasks (all, active, completed)**: View all tasks, only active ones, or completed ones with a single click.

- **Categories or priority levels**: Users will be able to priority levels (low, medium, high), and categories (work, personal, shopping, other).

- **Persist data with localStorage**: Your tasks are saved in your browser's local storage, so they stick around even after you close the tab.

## TECHNOLOGIES USED:

- HTML5: For the structure and semantic markup.
- CSS3: For styling, including gradients, animations, and responsive layouts.
- JavaScript: For all the interactive magic – no frameworks, just pure JS goodness.
